Make template buttons work with MAXTROIT

Use these attributes in your template HTML. They connect the design to real downloads and navigation.

  • data-maxtroit-downloads — live download cards appear here.
  • data-maxtroit-action="downloads" — scrolls to the download list.
  • data-maxtroit-search — live search input.
  • data-maxtroit-category — category filter select.
  • data-maxtroit-download-id="FIRESTORE_ID" — opens that download details page.
  • data-maxtroit-brand — shows your website name.
  • data-maxtroit-social — renders configured social links.

Template JavaScript can keep its own menus, tabs, accordions and animations. To connect a new custom feature to Firebase or admin data, it must use a supported MAXTROIT bridge action or have its own backend/API. Arbitrary code cannot be made fully functional automatically just by uploading a design.
