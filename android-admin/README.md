# Android Admin APK

The Android app now bundles the actual Admin Panel website files (admin.html, admin.js, supporting admin modules, CSS, and Firebase configuration) inside the APK. It does not ask for a website URL or act as a remote-site launcher.

## First run on your own Firebase project

1. Complete the independent Firebase setup in [FORK-SETUP-GUIDE.md](../FORK-SETUP-GUIDE.md).
2. In Firebase Console, open **Authentication → Settings → Authorized domains** and add:
   `appassets.androidplatform.net`.
   The bundled WebView uses this HTTPS app-assets origin for Firebase Authentication. Do not remove your own Hosting domain.
3. Build/install the APK generated by the GitHub Actions workflow. On first launch, the bundled setup screen appears until your own Firebase web config and admin UID are configured in the APK source.
4. Because the APK bundles its own copy of the web files, after changing Firebase config or Admin UI code, build a fresh APK. A deployed website update does not silently update the APK.

The app uses Firebase's browser SDK over HTTPS. It does not contain a Firebase service-account key or admin password. Firebase security rules and the admin UID remain the security boundary.

## Build

The workflow creates a debug APK artifact for testing. A debug APK is not a Play Store release and is not signed with a private production release key.
